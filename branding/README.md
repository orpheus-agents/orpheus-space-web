Brand assets for Orpheus, its connectors and docs. Everything in `logo/`,
`exports/` and `web/` is generated by [`scripts/build.py`](scripts/build.py).

## Files

`logo/`:

- `orpheus-logo.svg` — logo with light text, for dark backgrounds;
- `orpheus-logo-light.svg` — logo with dark text, for light backgrounds;
- `orpheus-logo-email.png` — raster of `orpheus-logo-light.svg`, 615×96, shown
  at 205×32 in emails;
- `orpheus-mark.svg` — the mark;
- `orpheus-mark-original.svg` — the mark as in the source raster, with the
  lower-left ribbon wrapping round the corner; kept for reference, other assets
  don't use it;
- `orpheus-mark-mono.svg` — one-colour mark, in `currentColor`;
- `orpheus-logo-mono.svg`, `orpheus-logo-mono-light.svg` — one-colour logo for
  dark and light backgrounds;
- `orpheus-wordmark.svg` — the wordmark alone, in `currentColor`.

`exports/` — square PNG of the mark, 512 and 1024 px: on the dark background,
and transparent with `-alpha`.

`web/` — favicons (SVG and PNG 16/32/48, transparent), Apple Touch Icon, PWA
icons 192 and 512 and maskable 512 on the dark background, `site.webmanifest`
and `favicon-snippet.html`. Copy the files to the site root as they are.

`interface/` — the interface guide's assets: `tokens.css` with the colour,
type and shape tokens for both themes, and the reference sessions screen,
`sessions-light.png` and `sessions-dark.png`. The screens are a reference
render, not generated by the script.

Inputs:

- `fonts/` — Martian Grotesk SemiExpanded (Bold, ExtraBold) and Martian Mono
  Condensed (Regular, SemiBold) by Evil Martians, SIL OFL 1.1
  ([Grotesk](fonts/OFL-MartianGrotesk.txt), [Mono](fonts/OFL-MartianMono.txt)).
  The wordmark uses Grotesk ExtraBold; the rest are for the interface;
- `source/orpheus-mark-source.png` — the raster the mark was vectorized from.

Guides: [colors.md](colors.md) for the palette, [interface.md](interface.md)
for the web UI.

## Mark

A regular hexagon ring of four ribbons with round ends. Going clockwise, each
ribbon's end lies over the tail of the next one. Proportions and gradients come
from the source raster; colours match it to about 3/255. In the raster, the
lower-left ribbon wraps round the corner and ends on the left edge; the mark
ends it straight at the corner.

In one colour the ribbons would merge into a solid ring, so each ribbon is cut
back around the round end lying on it: the cut follows the end's curve with a
gap of 11 units, about a fifth of the ribbon width. Below about 24 px the gaps
close up; use the colour mark there.

## Wordmark and logo

`ORPHEUS` is set in capitals in Martian Grotesk SemiExpanded ExtraBold (800),
the heading face of agentbox.ru, with −0.02 em tracking, kerned with HarfBuzz
and converted to outlines: no font is needed to display it.

In the logo, the mark is 1.4 cap heights tall and centred on the cap height,
so it rises a little above and below the letters. The gap is 0.3 of the mark
height.

## Build

```sh
uv run branding/scripts/build.py
uv run branding/scripts/test_build.py
```

uv installs the dependencies listed in the script header: fontTools, uharfbuzz,
resvg-py and skia-python, pinned because its path operations cut the mono
mark. Parameters are constants at the top of `build.py`: geometry, gradients,
the mono gap, tracking, logo proportions and colours. `MARK` picks the mark used
by the logo and icons, `ALT_MARK` the extra one in `logo/`: `"straight"` or
`"original"`.

Don't edit the generated files by hand: change the script and rebuild. The test
fails when committed SVG files differ from the script output.
